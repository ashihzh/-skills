# 反模式库（抽象通用，零任务内容）

> 把反复踩过的坑抽象成通用反模式，供规划与执行两侧引用。每条含：反模式名 / 现象 / 根因 / 规避 / 检测信号。
> **只写抽象模式**：本文件不含任何具体轮号、任务 slug、提交哈希、令牌片段、具体用户名或项目名——这是「母版零任务内容」铁律。

## 1. 文档说修好了 ≠ 现实改了

- **现象**：报告/文档声称「已修复」「已改完」，实际文件没变或变错，验收却照单全收。
- **根因**：把「写下结论」当成「完成事实」，没有现场读回。
- **规避**：改完后读回真实文件/配置/状态确认；报告之前先复核关键项现场值。
- **检测信号**：结论只有文字描述、没有命令输出/哈希/文件全文佐证。

## 2. 字符串存在即通过

- **现象**：验证只查文件是否含某字符串（如版本号、标记），忽略了它的位置与语境。
- **根因**：`grep -c "X"` 看似严谨，实则在错误语境也能命中，产生假阳性。
- **规避**：精确断言——解析出字段的真实值再比，而非「含字符串」；配负向测试证明断言能判 FAIL。
- **检测信号**：验证脚本只由 `grep`/`contains` 构成，没有值解析与比较。

## 3. 权限显示可写 ≠ 凭据真能写

- **现象**：权限字段/CI 设置显示 push=true、写权限已开，实际写入探针却被拒。
- **根因**：把「配置展示」当成「授权生效」，忽略细粒度令牌、作用域、审批等真实边界。
- **规避**：用真实写入探针验证，而非看权限显示；探测失败即上报，不重试绕过。
- **检测信号**：结论依据只有「设置页显示」，没有一次真实写入的回执。

## 4. 账号权限 ≠ 令牌权限

- **现象**：账号本身有权限，但自动化用的细粒度/个人令牌授权范围不包含该操作。
- **根因**：混淆「我是谁」与「我手里的凭据能做什么」。
- **规避**：探测时区分账号权限与令牌权限，分别验证；授权边界不清时停下来问用户，不猜测。
- **检测信号**：同一操作手工可做、脚本用 token 做失败，却归因于「网络/偶发」。

## 5. 前缀变体漏匹配

- **现象**：精确匹配时漏掉变体（如带 `v` 前缀的版本号、带后缀的路径），导致「没找到」或「匹配错行」。
- **根因**：先写了断言模式再猜文本形态，没先 dump 真实文本。
- **规避**：写精确断言前先把真实文本 dump 出来看清形态，再写匹配；对前缀/后缀变体逐一覆盖。
- **检测信号**：断言失败原因说「找不到」，但没人看过真实文本长什么样。

## 6. 脚本中的日期/反引号被 shell 提前替换

- **现象**：写文件时期望保留的 `date`、反引号、美元变量被 shell 在写入时就替换掉，文件内容变了样。
- **根因**：用了会展开内容的 heredoc 或未加引号的写法。
- **规避**：写含特殊字符的脚本/模板时用单引号 heredoc（`<<'EOF'`）或直接文件写入 API，写后读回验证。
- **检测信号**：生成文件里出现意外的实际日期/命令输出，而非字面量。

## 7. 跨平台 bash 误命中（WSL vs MSYS）

- **现象**：在 Windows 上调 `bash` 给了 WSL 而非预期的 MSYS，路径/权限/行为全不对。
- **根因**：环境里有多个 bash，未显式指定使用哪一个。
- **规避**：明确使用哪个 bash；脚本里避免依赖默认 PATH 中的 bash 解析，必要时用绝对路径或在命令里固定环境。
- **检测信号**：同一命令在「bash」与「显式路径 bash」下结果不同。

## 8. 头铁重试同一方法

- **现象**：同一方法失败两次仍原样试第三次，浪费时间且不产生新信息。
- **根因**：把「再试一次」当成进展，没有强制止损。
- **规避**：同一方法失败 2 次即停——换思路、查日志，或写进阻塞项上报；第三次原样重试是流程禁止。
- **检测信号**：连续多次调用参数几乎相同的失败命令。

## 9. 顺手修范围外问题带偏任务

- **现象**：执行中发现计划外的新问题，当场开修，主任务被带偏、范围失控。
- **根因**：把「发现问题」等同于「该我修」。
- **规避**：范围外问题只登记进 backlog（附证据），不当场开修；要修先走补规划拍板。
- **检测信号**：工作包的改动文件超出 plan.md 声明的写范围。

## 引用

- 规划侧：task-planner 的 `SKILL.md` 在澄清/风险登记时参考本库预判坑点。
- 执行侧：task-executor 的 `SKILL.md`「环境坑记录」沉淀时指向本库，避免同一坑跨任务重复踩。
- 新增反模式：只抽象成通用类型（现象/根因/规避/检测信号），**绝不写入具体任务内容**。
